# ds-copilot

A local, single-user **data-science co-pilot** dev environment: a VS Code/Cursor extension (UI) + Claude Code skills + supporting code that augments Claude Code in-IDE, tracking the research logic as a DAG.

Status: **specification / wayfinding**. The spec is being charted as GitHub Issues.

- **Map**: the issue labelled `wayfinder:map` is the canonical index (destination, decisions, fog).
- **Tickets**: child issues of the map, labelled `wayfinder:<type>` (`research`/`prototype`/`grilling`/`task`).
- **Research assets**: `.scratch/ds-copilot/research/`.
